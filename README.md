# DS160_Final_Project_EJL
DS160 Final Project - Stroke Risk Prediction

Abstract:
This project explores stroke risk prediction using a dataset of various symptoms. The analysis includes a regression models that addresses two main questions: 1) What is the percentage likelihood of a person experiencing a stroke? and 2) Based on their symptoms, is the person at risk of a stroke? Exploratory data analysis was conducted to understand patterns in stroke risk, symptom presence, and age. A new variable was added to this dataset, # of Symptoms, to better find a correlation between stroke risk and symptoms. A linear regression model was used to predict stroke risk percentage to find if an individual is at risk for a stroke or not. Model accuracy was evaluated using metrics like RMSE, R², accuracy, and confusion matrices. The results suggest that certain symptoms, age, and symptom count are positively correlated with stroke risk.
